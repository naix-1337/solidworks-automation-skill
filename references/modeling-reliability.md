# 原生建模防错流程

适用于 SolidWorks COM 原生建模、草图尺寸和实体特征；不改变用户指定的建模顺序、版本、输出路径及授权范围。普通已验证封装直接复用，仅对新接口、易失设置、自动约束和失败步骤增加检查。关键词：`GetActiveObject`、`CreateSelectData`、`FullyDefineSketch`、`IsClosed`、尺寸输入框、检查点。

## 1. 先确认实例与文档

- 运行 `sw_preflight.py`，再由 `SolidWorksSession` 建立连接；记录实际版本、revision、PID、当前文档标题和路径。指定目标版本或实例时按目标校验，不能把默认 ProgID 当作实际版本证明。
- `GetActiveObject` 失败不等于未安装或未运行。检查已有进程、权限上下文、桌面会话/ROT 可见性和实例就绪状态。使用现有连接错误中的阶段和错误码；只有确认没有适用实例且允许启动时，才由受控连接器创建实例。
- 没有新诊断时不重复 `Dispatch`。需要不同权限上下文时按当前环境的授权机制处理，不能把本机一次提权成功写成所有环境均须提权。
- 修改前绑定目标文档；多实例不靠活动窗口猜测。只关闭本任务登记的文档，不靠“未保存”或文件名相似推断归属。

## 2. 新 API 先验证调用合同

先按 `api-lookup.md` 查目标版本的所属接口、属性/方法形式、参数、单位、选择标记和返回值。`GetConstrainedStatus` 应用于草图，不能把该成员假定在草图点上也存在。

无参数 COM 成员优先使用 `get_com_member(obj, "Member")`。例如先取得 SelectionManager，再以 `get_com_member(manager, "CreateSelectData")` 获取选择数据。pywin32 的伪可调用属性不能仅凭 `callable()` 决定是否加括号。带参数的方法按已核对签名调用；不要遇到任意异常就尝试第二种写法，避免重复执行有副作用的操作。

未封装的新操作在本任务临时文档中验证：有效选择集、返回对象、特征重建和实际结果。参数正确且可重复执行后才接入完整流程。稳定逻辑复用公共封装；不需要为已验证的每次普通调用重新创建试验模型。

## 3. 尺寸输入与临时设置

```python
from sw_modeling_guard import dimension_input_guard

with dimension_input_guard(session.sw):
    # 在此创建及检查实际驱动尺寸，异常也会恢复原设置。
    build_dimensioned_sketch(model)
```

此函数临时关闭 `swInputDimValOnCreate`，并回读设置是否生效，退出时恢复进入前的真实值。SolidWorks 全局设置修改必须串行执行。`AddToDB`、自动关系等其它临时设置同样记录原值并在 `finally` 恢复，不能把默认值当作原值。

尺寸创建后立即确认参数所属草图/几何、数值和驱动/从动状态。接口返回非空不代表选中了预期实体。遇到长时间无输出，先检查本任务窗口和输入框；确认具体对话框、所属进程及内容后再处理，禁止向未知活动窗口盲发回车。外部等待超时不表示正在执行的 COM 调用已经取消；确认调用已结束或经受控取消后才可恢复写操作。

## 4. 约束状态与尺寸保持分别检查

- 复杂剖面先从图纸形成坐标/尺寸表，明确原点、轴线、重合、相切和对称等设计关系。先添加设计关系，再补剩余自由度；不对全部草图统一套用全部自动关系。
- `FullyDefineSketch` 可能移动初始几何。状态为完全定义只能证明自由度已消除，不能证明尺寸与原设计相同，也不能证明轮廓闭合。
- 对直线、圆弧和圆，可使用 `guarded_fully_define_sketch(model, tolerance_m=...)`。调用者事先选择数值比较容差，单位为米；它不是制造公差，不能扩大容差来放过真实的尺寸偏移。默认关系掩码 `518` 只包含水平、垂直、重合；需要的相切、同心、相等关系显式建立，不能把该掩码当作所有草图的通用解法。
- 函数保留实体引用，比较求解前后的端点、圆心、半径和实体数量；整圆忽略无几何意义的接缝方向。超限立即报错，保留证据并暂停后续特征。圆/矩形基础流程仍可用原有 `fully_define_sketch()`；显式传 `relations_to_apply=0` 可只补尺寸，但仍须检查是否完全定义。
- 样条、椭圆等不在公共几何比较器范围内，须提供该任务的尺寸/几何不变量读取器，不能跳过检查后声称通过。该检查仅阻止求解器意外移动，初始坐标本身仍须与图纸核对。
- 不使用批量 Fix 伪造参数化。保存重开后仍需检查尺寸、关系、草图消费状态，以及关键参数修改后可重建。

## 5. 特征前检查轮廓与材料区域

退出草图后，对需要封闭轮廓的实体拉伸/旋转调用：

```python
from sw_modeling_guard import require_closed_contours

closure = require_closed_contours(sketch_ref.sketch, expected_count=2)
```

`expected_count=2` 仅是“一个外轮廓和一个孔轮廓”的例子，实际数量来自设计。读取轮廓的真实 `IsClosed`，不能用屏幕上端点重叠作为闭合证明。圆弧与直线按设计补端点重合、相切关系，再重新读取闭合状态。

该函数只检查闭合与数量，重复线、自交、内外环嵌套、应选区域仍须另行检查；不能将其返回值解释为拓扑全部有效。开放轮廓的薄壁/曲面/扫描按对应特征规则处理。

特征执行前记录草图局部坐标与法向、起点偏置、终点/深度、方向、合并和实体作用范围。新增法兰、耳台等材料时，同时明确保留的孔区，防止新增材料填住已有通孔。方向或合并条件不确定时只隔离验证该步骤，不在整套模型中反复猜方向。

执行后立即检查返回值、重建和预期实体数量，再读取关键几何/体积变化或局部剖面，确认材料增减正确。选边采用语义几何与预期数量，清理残留选择集；延续圆角/倒角子技能的选边要求。

## 6. 失败记录与检查点恢复

首次确定性失败即停止依赖步骤，保留阶段、异常/COM 错误码、PID、目标文档、活动草图、选择集、闭合结果、关键参数和返回值。未知状态不得写成成功。

只有出现新诊断和对应修改后才重试。连接就绪等待等已识别的瞬时失败可以采用有时限、适合该操作的重试；确定性接口、轮廓或尺寸错误不能原样重跑。不要机械规定所有失败都重试若干次。

检查点放在本任务脚本/审查目录，记录输入及参数版本、实例/文档归属、已完成特征和参数、原生文件路径/哈希、当前健康状态。只有通过当前阶段检查才登记成功。恢复时重新读取这些证据；文档变化、缺失特征或参数不一致就拒绝直接续跑，从最近可验证阶段恢复。不能仅凭最后一行日志或旧 COM 对象继续。

重试和返工沿用原任务目录及重名文件规则；不自动覆盖用户原有最终文件，不清理其它任务或用户文档。结束时清理本任务临时文档并核对最终目录。

## 验证范围

公共检查可通过替身单元测试验证异常恢复、尺寸漂移拦截、开放轮廓拒绝等行为，再在目标 SolidWorks 版本对圆/矩形和一项代表性复杂剖面进行最小原生验证。API 查证与真机证据分开记录，不将一个版本的试验结果扩展为所有版本均通过。

这些检查是建模过程诊断；交付仍遵循 `run_review()`、保存重开、视觉核对和生产尺寸签名证据规则，不将本机自行生成的检查记录升级成制造尺寸 PASS。
